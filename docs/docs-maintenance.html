Rolling release

System maintenance

Back up personal files before major changes and keep your installation USB available. Read current release notes before a large update, then use Zelix Updater or sudo pacman -Syu. Let package operations finish and restart when a kernel or driver update requires it.

Check free space and configuration changes

Low disk space can interrupt downloads and updates. Review free space with df -h. Package updates may place new configuration defaults in .pacnew files; compare these with your edited files and merge needed changes instead of blindly replacing either version.

df -h
sudo find /etc -name '*.pacnew' -print

When an update fails

Record the exact error. Check network access, free space, and whether another package process is running. Resolve the cause before retrying a full update. Avoid deleting pacman lock files while a package operation is active.

Before a large update

Read the ZelixOS release notes and any relevant Arch news, back up important data, and ensure the system has enough free space and a stable connection. Run one complete update with Zelix Updater or sudo pacman -Syu. Do not run a second package manager while the first is working. Restart after kernel or driver updates when the tool asks for it.

Back up what matters

Keep a copy of personal files and important settings on another drive or trusted storage. A snapshot on the same disk is helpful for some configuration mistakes but will not survive that disk failing. Check that you can actually open a restored file before relying on a backup. Keep the live USB available for boot recovery.

Review .pacnew files and the package cache

When an updated package ships a new default configuration, pacman may create a .pacnew file. Compare it with your current file and merge the needed settings. Do not overwrite a working configuration blindly. The package cache can help with recovery; inspect its size before cleaning it. Use the Zelix CLI cleanup feature only after reading what your installed version does.

sudo find /etc -name '*.pacnew' -print
du -sh /var/cache/pacman/pkg

Büyük güncelleme öncesinde

ZelixOS sürüm notlarını ve ilgili Arch duyurularını okuyun, önemli verileri yedekleyin; yeterli boş alan ve kararlı bağlantı sağlayın. Zelix Updater veya sudo pacman -Syu ile tek bir tam güncelleme yapın. İlki çalışırken ikinci paket yöneticisini başlatmayın. Araç gerektiğini belirttiğinde çekirdek veya sürücü güncellemesinden sonra yeniden başlatın.

Önemli verileri yedekleme

Kişisel dosyaların ve önemli ayarların bir kopyasını başka bir sürücüde veya güvenilir depolamada tutun. Aynı diskteki anlık görüntü bazı yapılandırma hatalarını geri alabilir, ancak disk bozulursa onu koruyamaz. Yedeğe güvenmeden önce geri yüklenen bir dosyayı gerçekten açabildiğinizi deneyin. Önyükleme kurtarması için canlı USB’yi saklayın.

.pacnew dosyaları ve paket önbelleği

Güncellenen paket yeni varsayılan yapılandırma sunduğunda pacman bir .pacnew dosyası oluşturabilir. Mevcut dosyanızla karşılaştırıp gerekli ayarları birleştirin. Çalışan yapılandırmanın üzerine düşünmeden yazmayın. Paket önbelleği kurtarmada işe yarayabilir; temizlemeden önce boyutunu inceleyin. Zelix CLI temizleme özelliğini yalnızca kurulu sürümün ne yaptığını okuduktan sonra kullanın.

sudo find /etc -name '*.pacnew' -print
du -sh /var/cache/pacman/pkg
