Installation · Guided setup

Zelix Installer

ZelixOS 1.0.0 includes the Zelix Installer, a graphical setup tool built around the official archinstall library. In the live environment, connect to the internet and open Install ZelixOS from the desktop.

01

Welcome and system scan

The installer checks basic hardware, boot mode, and network availability. Resolve connection issues before continuing.

02

Select a desktop and greeter

Choose from the desktop options presented by your installer, including KDE Plasma, GNOME, Xfce, Hyprland, Sway, i3, or bspwm. Display-manager choices may include SDDM, GDM, LightDM, or Ly. The installer also lets you choose whether an AUR helper will be installed. Select it only if you plan to use AUR packages.

03

Select the disk and bootloader

Review the detected NVMe, SSD, or HDD devices and choose the target carefully. Configure the available bootloader option, such as systemd-boot or GRUB. Choose the filesystem and layout shown by your installer; check each formatting action in its final summary.

04

Configure accounts

Set the hostname, a strong root password, and your everyday user account. Keep credentials private and store them securely.

05

Install and review progress

Confirm the configuration before starting. The installer shows a live log while packages are downloaded and installed; do not power off during this process.

Before you confirm

  • Check that the selected target is the intended disk, especially when multiple drives are attached.
  • Review every partition marked for formatting. If another operating system must remain, do not continue until its partitions are preserved.
  • Check boot mode, desktop choice, user account, and the optional AUR helper choice in the final summary.
Review the disk summary

Disk formatting is destructive. If you need to preserve another operating system or existing files, stop and verify the partition plan before starting.

Installing on an empty dedicated disk

Back up any data that might still be on the disk. In the installer, compare the disk model and capacity with the physical drive before selecting it. Review the final summary to see which partitions will be created or formatted. Confirm only when the entire selected disk may be used for ZelixOS.

Keeping another operating system

Make a full backup of that system first. Identify its disk and EFI partition before opening the installer. If the current installer does not show a partition layout that clearly preserves them, stop; do not guess at a destructive option. Using a separate disk can simplify the layout, but you still need to check which disk receives the boot entry.

If installation stops

Stay in the live session, keep the network connected, and copy the exact stage and error message. Note which desktop, bootloader, disk, and optional AUR helper choices were made. Avoid restarting or reformatting until you have checked the logs shown by Zelix Installer and identified the failed step.

Boş ve yalnızca ZelixOS’a ayrılmış diske kurulum

Diskte hâlâ bulunabilecek verileri yedekleyin. Yükleyicide disk modelini ve kapasitesini fiziksel sürücüyle karşılaştırıp hedefi seçin. Son özette hangi bölümlerin oluşturulacağını veya biçimlendirileceğini inceleyin. Yalnızca seçilen diskin tamamı ZelixOS için kullanılabiliyorsa onaylayın.

Başka bir işletim sistemini koruyarak kurulum

Önce o sistemin tam yedeğini alın. Yükleyiciyi açmadan diskini ve EFI bölümünü belirleyin. Mevcut yükleyici onları açıkça koruyan bir bölüm düzeni göstermiyorsa durun; veri silecek bir seçeneği tahmin ederek kullanmayın. Ayrı disk düzeni sadeleştirebilir, ancak önyükleme girdisinin hangi diske yazılacağını yine de kontrol edin.

Kurulum durursa

Canlı oturumda kalın, ağ bağlantısını açık tutun ve aşama ile hata iletisini aynen kaydedin. Seçilen masaüstünü, önyükleyiciyi, diski ve isteğe bağlı AUR yardımcısını not edin. Zelix Yükleyici’nin gösterdiği günlükleri inceleyip başarısız adımı belirlemeden yeniden başlatmayın veya diski tekrar biçimlendirmeyin.

A practical installation walkthrough

1. Prepare and start the live session

Back up the files you need, check the system requirements, and verify the downloaded ISO. Write it to a USB drive using the installation media guide. Boot from the USB using your firmware's boot menu. Connect to the internet in the live desktop and confirm that a website opens before starting Install ZelixOS.

2. Identify the target disk

Disconnect unnecessary external drives if practical. In a terminal, lsblk -o NAME,SIZE,MODEL,FSTYPE,MOUNTPOINTS lists disks and partitions; use the model and size together to identify the target. This command only displays information. The live USB also appears in the list, so do not select a device based on its name alone.

lsblk -o NAME,SIZE,MODEL,FSTYPE,MOUNTPOINTS

3. Review setup choices

Choose the language, desktop, login manager, disk layout, bootloader and account options offered by your installer version. Check that the selected disk and every formatting action match your plan. If preserving an existing system, verify its partitions and EFI partition will be retained; stop if the summary does not make this clear. Store the credentials somewhere secure.

4. Install, then start the installed system

Read the final summary before confirming. Keep power and internet connected while the installer runs. Once it reports success, restart and remove the USB when appropriate. Select the installed system in the firmware boot menu if needed, then sign in with the account you created. Continue with post-installation; if it does not boot, see boot and recovery.

When something goes wrong

Record the exact message and installation stage, along with the ISO version, target disk, boot mode, desktop and bootloader choices. Check the connection and available space, then consult troubleshooting. Do not share passwords or private details from logs.

Adım adım kurulum

1. Hazırlık ve canlı oturum

Gerekli dosyalarınızı yedekleyin, sistem gereksinimlerini kontrol edin ve indirdiğiniz ISO’yu doğrulayın. Kurulum medyası rehberiyle USB hazırlayın. Bilgisayarın önyükleme menüsünden USB’yi başlatın. Canlı masaüstünde internete bağlanın ve ZelixOS kurulumunu açmadan önce bir web sitesinin yüklendiğini doğrulayın.

2. Hedef diski belirleyin

Mümkünse gerekli olmayan harici sürücüleri çıkarın. Terminalde lsblk -o NAME,SIZE,MODEL,FSTYPE,MOUNTPOINTS diskleri ve bölümleri listeler; hedefi belirlemek için model ve kapasiteyi birlikte kontrol edin. Bu komut yalnızca bilgi gösterir. Canlı USB de listede görünür; yalnızca aygıt adına bakarak seçim yapmayın.

lsblk -o NAME,SIZE,MODEL,FSTYPE,MOUNTPOINTS

3. Kurulum seçimlerini gözden geçirin

Yükleyici sürümünüzün sunduğu dil, masaüstü, giriş yöneticisi, disk düzeni, önyükleyici ve hesap seçeneklerini belirleyin. Seçilen diskin ve her biçimlendirme işleminin planınıza uyduğunu kontrol edin. Başka bir sistemi koruyorsanız bölümlerinin ve EFI bölümünün korunacağını doğrulayın; özet açık değilse durun. Giriş bilgilerinizi güvenli bir yerde saklayın.

4. Kurun ve kurulu sistemi başlatın

Onaylamadan önce son özeti okuyun. Kurulum sırasında güç ve internet bağlantısını koruyun. Başarı bildirildikten sonra yeniden başlatın ve uygun zamanda USB’yi çıkarın. Gerekirse önyükleme menüsünden kurulu sistemi seçin ve oluşturduğunuz hesapla giriş yapın. Kurulum sonrası adımlarla devam edin; sistem açılmazsa önyükleme ve kurtarma rehberine bakın.

Bir sorunla karşılaşırsanız

Hata mesajını ve kurulum aşamasını aynen kaydedin; ISO sürümünü, hedef diski, önyükleme kipini, masaüstü ve önyükleyici seçimlerini not edin. Bağlantıyı ve boş alanı kontrol edip sorun giderme rehberine bakın. Günlüklerdeki parolaları ve özel bilgileri paylaşmayın.
