i3

i3

i3 is a tiling window manager for X11. Its configuration is commonly stored at ~/.config/i3/config. Read that file for the chosen Mod key, terminal, launcher, workspace bindings, and status bar. i3's first-run configuration may ask you to choose a Mod key.

Useful checks: i3-msg reload rereads the config; i3-msg -t get_outputs lists outputs. A config syntax or missing launcher command can make shortcuts appear broken. Use i3 -C to validate the configuration before restarting the session.

i3 -C
i3-msg reload

i3 user guide

ZelixOS setup

ZelixOS includes ~/.config/i3/zelix.conf from the main config for borders, gaps and wallpaper via feh. Back up both files before editing; keep the include if you want these defaults. Review the actual bindings in your config instead of assuming a particular Mod key.

i3

i3, X11 için döşemeli pencere yöneticisidir. Yapılandırma genellikle ~/.config/i3/config konumundadır. Mod tuşu, terminal, başlatıcı, çalışma alanı kısayolları ve durum çubuğu için bu dosyayı okuyun. İlk açılışta Mod tuşunu seçmeniz istenebilir.

Yararlı kontroller: i3-msg reload yapılandırmayı yeniden okur; i3-msg -t get_outputs ekranları listeler. Yapılandırma hatası veya eksik başlatıcı komutu kısayolları bozuk gösterebilir. Oturumu yeniden başlatmadan önce i3 -C ile dosyayı doğrulayın.

i3 -C
i3-msg reload

i3 kullanım kılavuzu

ZelixOS kurulumu

ZelixOS kenarlık, boşluk ve feh ile duvar kâğıdı için ~/.config/i3/zelix.conf dosyasını ana yapılandırmaya dahil eder. Düzenlemeden önce iki dosyayı da yedekleyin; bu varsayılanları korumak için include satırını bırakın. Mod tuşunu ve kısayolları kendi yapılandırmanızdan kontrol edin.
