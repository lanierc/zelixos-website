Software · Zelix Hello

Install applications with Zelix Hello

For everyday applications, start with Zelix Hello rather than searching for a separate download on the web. Its Software page groups supported applications and lets you install an individual program with one click. The available catalog can change between ZelixOS releases.

Example entries based on the Zelix Hello Software screen. The exact catalog may vary by release.

  1. 01

    Open Zelix Hello

    Launch Zelix Hello from the application menu or use the welcome shortcut on the desktop.

  2. 02

    Choose Software

    Open the Software page to see the application groups available on your installed version.

  3. 03

    Select one application

    Choose the individual app’s Install button (shown as Kur in the Turkish interface). The group-wide button Install all / Tümünü Kur installs every app in that category, so use it only if that is what you want.

  4. 04

    Let installation finish

    Keep the computer connected to the internet, approve any system authentication prompt, and wait for the install operation to complete.

Prefer Zelix Hello when an app is listed there

When another guide recommends installing a program, first check Zelix Hello → Software. If it is not listed, use the app’s official installation guidance or the current ZelixOS package-manager documentation. Avoid downloading installers from unfamiliar websites.
