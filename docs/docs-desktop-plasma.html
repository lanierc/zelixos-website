Masaüstü rehberleri

KDE Plasma

KDE Plasma

The styled Plasma desktop is the main ZelixOS experience. Use System Settings for display arrangement and scaling, keyboard layouts, audio, power, and workspace behavior. Right-click the desktop or panel to adjust widgets. KRunner opens apps and searches commands; the launcher shortcut may depend on the installed configuration.

Useful checks: Open System Settings from the app menu or with systemsettings. If panels disappear while apps still work, first log out and back in. If only one display is missing, check System Settings → Display and Monitor and inspect its enabled state and refresh rate. Record whether the session is Wayland or X11 before reporting rendering problems.

KDE documentation

ZelixOS setup

Start with the application launcher and System Settings. The panel and its widgets can be customized from their context menus. If more than one desktop is installed, choose Plasma on the login screen before signing in.

KDE Plasma

ZelixOS’un öne çıkan görünümlü masaüstü Plasma’dır. Ekran düzeni ve ölçekleme, klavye, ses, güç ve çalışma alanı davranışı için Sistem Ayarları’nı kullanın. Araç takımlarını düzenlemek için masaüstüne veya panele sağ tıklayın. KRunner uygulama açar ve komut arar; kısayolu kurulu yapılandırmaya bağlı olabilir.

Yararlı kontroller: Sistem Ayarları’nı uygulama menüsünden veya systemsettings ile açın. Uygulamalar çalışırken yalnızca panel kaybolursa önce oturumu kapatıp yeniden açın. Tek bir ekran görünmüyorsa Sistem Ayarları → Ekran ve Monitör bölümünde etkinlik durumunu ve yenileme hızını kontrol edin. Görüntü hatasını bildirirken oturumun Wayland mı X11 mi olduğunu kaydedin.

KDE belgeleri

ZelixOS kurulumu

Uygulama başlatıcısı ve Sistem Ayarları ile başlayın. Paneli ve araç takımlarını sağ tık menülerinden düzenleyebilirsiniz. Birden fazla masaüstü kuruluysa giriş ekranında Plasma oturumunu seçin.

Everyday use

Getting around

Open the application launcher to find installed programs, and use the panel to switch between windows. Use the desktop and panel context menus to adjust widgets; record your preferred layout before making large changes.

Displays, input and sound

Open System Settings to arrange monitors, set scaling and select keyboard layouts. Check the selected input and output in Sound when a microphone or speakers do not work. Apply display changes only after checking that each screen remains usable.

Session and troubleshooting

Choose Plasma at the login screen if multiple sessions are installed. To identify the current session type, run echo $XDG_SESSION_TYPE in a terminal. If login returns to the greeter, check free space and collect the user journal as described in troubleshooting.

Günlük kullanım

Masaüstünde gezinme

Kurulu programları uygulama başlatıcısından bulun; pencereler arasında geçmek için paneli kullanın. Araç takımlarını masaüstünün ve panelin sağ tık menülerinden düzenleyin; büyük değişikliklerden önce tercih ettiğiniz düzeni not edin.

Ekran, giriş ve ses

Monitörleri düzenlemek, ölçeklemeyi ve klavye düzenlerini seçmek için Sistem Ayarları’nı açın. Mikrofon veya hoparlör çalışmıyorsa Ses bölümündeki giriş ve çıkışı kontrol edin. Ekran değişikliklerini uygularken her ekranın kullanılabilir kaldığını doğrulayın.

Oturum ve sorun giderme

Birden fazla oturum kuruluysa giriş ekranında Plasma’yı seçin. Oturum türünü görmek için terminalde echo $XDG_SESSION_TYPE çalıştırın. Giriş ekranına geri dönüyorsanız boş alanı kontrol edin ve sorun giderme rehberindeki kullanıcı günlüğünü toplayın.
