Sway

Sway

Sway is an i3-style Wayland compositor. Check ~/.config/sway/config for actual shortcuts and output settings. Its example configuration commonly uses the Mod key with Enter for a terminal and Mod+Shift+C to reload, but verify the installed config first.

Useful checks: swaymsg -t get_outputs identifies displays and modes; swaymsg -t get_inputs identifies keyboards and pointing devices; swaymsg reload applies configuration changes. If a monitor stays dark, inspect its output name before adding an output rule.

swaymsg -t get_outputs
swaymsg reload

Sway documentation

ZelixOS setup

ZelixOS adds ~/.config/sway/zelix.conf for borders, gaps and wallpaper, included from the main config. Back up both files before editing. Use sway -C to check configuration syntax before reloading; inspect any reported line and keep a terminal open.

Sway

Sway, i3 tarzında bir Wayland bileştiricisidir. Gerçek kısayollar ve ekran ayarları için ~/.config/sway/config dosyasını kontrol edin. Örnek yapılandırmada terminal için Mod+Enter, yeniden yükleme için Mod+Shift+C yaygındır; önce kurulu dosyayı doğrulayın.

Yararlı kontroller: swaymsg -t get_outputs ekranları ve modları, swaymsg -t get_inputs klavye ve işaretleme aygıtlarını listeler; swaymsg reload yapılandırmayı uygular. Ekran karanlık kalırsa çıkış kuralı eklemeden önce çıkış adını belirleyin.

swaymsg -t get_outputs
swaymsg reload

Sway belgeleri

ZelixOS kurulumu

ZelixOS kenarlık, boşluk ve duvar kâğıdı için ana dosyadan dahil edilen ~/.config/sway/zelix.conf dosyasını ekler. Düzenlemeden önce iki dosyayı da yedekleyin. Yeniden yüklemeden önce sway -C ile sözdizimini kontrol edin; bildirilen satırı inceleyin ve terminali açık tutun.
