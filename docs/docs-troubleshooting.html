Troubleshooting

Start with these basic checks before changing system configuration.

Use the checks below from the affected installed system unless a step says live USB. Start with read-only commands and record what you find. A command missing on your installation is useful information; do not install random packages just to make a diagnostic command run.

1. Collect the basics

Note the ZelixOS release, desktop, session type, kernel, hardware, and when the problem started. The commands below show the running kernel, PCI devices, disk layout, and recent errors from this boot. System logs may need administrator rights. Check output for private names, paths, and addresses before sharing.

uname -r
lspci -k
lsblk -f
sudo journalctl -b -p err --no-pager -n 80

2. Desktop will not open or login loops

At the greeter, select the desktop that was installed. If the screen returns to the greeter, switch to a text console with Ctrl+Alt+F3 and sign in. Check free space and failed user services. A full root partition can prevent sessions from starting. Record recent user journal messages; do not delete desktop configuration files before backing them up.

df -h
systemctl --user --failed
journalctl --user -b --no-pager -n 80

If the text console also fails, use the live USB to inspect disks and collect the visible error. A blank graphical screen after changing a Hyprland, Sway, i3, or bspwm config should prompt a check of that config and its most recent edit.

3. Network connects but downloads fail

First check whether websites load and whether the problem affects every application or only pacman. If NetworkManager is present, nmcli device status shows device state. ip route shows the selected route. A missing route points to a connection problem; a pacman-only failure can indicate an outdated mirror or package database. Use Zelix Hello's mirror action or a full system update after confirming connectivity.

nmcli device status
ip route
sudo pacman -Syu

Never use pacman -Sy alone as a workaround. If a mirror returns 404, note the package name and mirror URL before changing settings.

4. Updates stop or pacman says the database is locked

Check whether Zelix Updater, pacman, or an AUR helper is still running. A lock can protect an active transaction. Wait for the operation to finish; never remove the lock while it is active. If an operation was interrupted, record the exact error and ask for help with the stale lock after verifying all package processes have stopped. Check free space and retry a full update only after the cause is clear.

ps -ef | grep -E '[p]acman|[y]ay|[p]aru'
df -h

5. No audio, microphone, or Bluetooth

Check the selected input and output in your desktop settings, mute state, and the app's own device selection. For PipeWire systems, wpctl status lists sinks and sources. If that command is unavailable, record it and check whether PipeWire and WirePlumber are running for your user. Bluetooth issues should also be checked against airplane mode and adapter state.

wpctl status
systemctl --user status pipewire wireplumber

Do not restart or replace audio services until you know which component is failing.

6. A monitor is missing or the screen is black

Test the cable and input selection first. KDE, GNOME, and Xfce provide display settings. In Hyprland use hyprctl monitors; in Sway use swaymsg -t get_outputs; in i3 use i3-msg -t get_outputs. Note whether the display is detected, which session type you use, and the GPU driver reported by lspci -k. Do not install a generic NVIDIA package before identifying the card and kernel.

7. What to include in a support report

Write a short title describing the symptom. Include the ISO/release, desktop or WM, Wayland or X11, hardware model, exact error text, steps to reproduce, what you already tried, and relevant command output. State whether the problem started after an update or a configuration change. Redact account names, Wi-Fi credentials, tokens, and other private data.

Aksi belirtilmedikçe aşağıdaki kontrolleri sorun yaşanan kurulu sistemde yapın; canlı USB adımlarını ayrıca belirttik. Önce yalnızca bilgi okuyan komutları kullanıp bulguları kaydedin. Bir komutun kurulu sistemde bulunmaması da yararlı bilgidir; sırf tanılama komutu çalışsın diye rastgele paket yüklemeyin.

1. Temel bilgileri toplayın

ZelixOS sürümünü, masaüstünü, oturum türünü, çekirdeği, donanımı ve sorunun ne zaman başladığını not edin. Aşağıdaki komutlar çalışan çekirdeği, PCI aygıtlarını, disk düzenini ve bu açılıştaki son hataları gösterir. Sistem günlükleri yönetici yetkisi isteyebilir. Paylaşmadan önce çıktıda özel ad, yol ve adres olup olmadığını kontrol edin.

uname -r
lspci -k
lsblk -f
sudo journalctl -b -p err --no-pager -n 80

2. Masaüstü açılmıyor veya giriş döngüsü yaşanıyor

Giriş ekranında kurduğunuz masaüstünü seçin. Ekran tekrar giriş ekranına dönüyorsa Ctrl+Alt+F3 ile metin konsoluna geçip oturum açın. Boş alanı ve başarısız kullanıcı servislerini kontrol edin. Dolu kök bölüm oturumun açılmasını engelleyebilir. Son kullanıcı günlüklerini kaydedin; masaüstü yapılandırma dosyalarını yedeklemeden silmeyin.

df -h
systemctl --user --failed
journalctl --user -b --no-pager -n 80

Metin konsolu da açılmıyorsa canlı USB ile diskleri inceleyip ekrandaki hatayı kaydedin. Hyprland, Sway, i3 veya bspwm yapılandırması değiştikten sonra siyah ekran oluştuysa dosyanın son düzenlemesini kontrol edin.

3. Ağ bağlı ama indirmeler başarısız

Önce sitelerin açılıp açılmadığına, sorunun tüm uygulamalarda mı yalnız pacman’da mı görüldüğüne bakın. NetworkManager varsa nmcli device status aygıt durumunu gösterir. ip route seçilen rotayı gösterir. Rota yoksa bağlantı sorunu olabilir; yalnız pacman hata veriyorsa yansı veya paket veritabanı güncelliğini kontrol edin. Bağlantıyı doğruladıktan sonra Zelix Hello’nun yansı aracını ya da tam sistem güncellemesini kullanın.

nmcli device status
ip route
sudo pacman -Syu

Geçici çözüm olarak pacman -Sy komutunu tek başına çalıştırmayın. Bir yansı 404 döndürüyorsa ayarları değiştirmeden önce paket adını ve yansı adresini kaydedin.

4. Güncelleme duruyor veya pacman veritabanı kilitli diyor

Zelix Updater, pacman veya AUR yardımcısının hâlâ çalışıp çalışmadığını kontrol edin. Kilit, etkin işlemi koruyor olabilir. İşlem bitene kadar bekleyin; etkin işlem sırasında kilidi silmeyin. İşlem yarıda kesildiyse tam hatayı kaydedin ve bütün paket süreçlerinin durduğunu doğruladıktan sonra eski kilit için yardım isteyin. Nedeni anlamadan tam güncellemeyi tekrarlamayın; boş alanı da kontrol edin.

ps -ef | grep -E '[p]acman|[y]ay|[p]aru'
df -h

5. Ses, mikrofon veya Bluetooth çalışmıyor

Masaüstü ayarlarında seçilen giriş ve çıkışı, sessiz modunu ve uygulamanın kendi aygıt seçimini kontrol edin. PipeWire sistemlerinde wpctl status ses çıkış ve girişlerini listeler. Komut yoksa bunu not edin ve kullanıcı için PipeWire ile WirePlumber’ın çalışıp çalışmadığını inceleyin. Bluetooth için uçak modunu ve bağdaştırıcının etkinliğini de kontrol edin.

wpctl status
systemctl --user status pipewire wireplumber

Hangi bileşenin bozuk olduğunu anlamadan ses servislerini yeniden başlatmayın veya değiştirmeyin.

6. Ekran görünmüyor veya siyah kalıyor

Önce kabloyu ve monitörün giriş seçimini deneyin. KDE, GNOME ve Xfce ekran ayarları sunar. Hyprland’da hyprctl monitors, Sway’de swaymsg -t get_outputs, i3’te i3-msg -t get_outputs kullanın. Ekranın algılanıp algılanmadığını, oturum türünü ve lspci -k çıktısındaki GPU sürücüsünü not edin. Kartı ve çekirdeği belirlemeden genel bir NVIDIA paketi yüklemeyin.

7. Destek bildirimine neler eklemeli?

Belirtiyi anlatan kısa bir başlık yazın. ISO/sürüm, masaüstü veya pencere yöneticisi, Wayland ya da X11, donanım modeli, tam hata metni, tekrarlama adımları, denedikleriniz ve ilgili komut çıktılarını ekleyin. Sorunun güncelleme veya yapılandırma değişikliği sonrasında başlayıp başlamadığını belirtin. Hesap adlarını, Wi-Fi parolalarını, anahtarları ve diğer özel bilgileri gizleyin.

ZelixOS projesi ve hata takibi

The live USB will not start

Verify the ISO against the checksum for its release, then write it to the entire USB device again. Try the firmware's one-time boot menu. Aurora 1.0.0 recommends UEFI with Secure Boot disabled. Record any on-screen error before changing firmware settings.

The installer cannot connect to the internet

Connect from the live desktop's network controls, then open a website to confirm access. Try Ethernet if Wi-Fi is unavailable. Record the network adapter model and the exact installer error if it still fails.

The installer cannot see the target disk

Check that the disk appears in the firmware and in the live session with lsblk -f. Record the disk model and current storage-controller setting. Do not change controller mode or erase partitions without a backup and a recovery plan for any existing operating system.

The computer boots to the old operating system

Remove the USB drive and select the installed ZelixOS entry from the firmware boot menu. If it is absent, follow the boot and recovery checks and record the boot mode and partition layout.

An update fails

Record the complete error, check the network and free space with df -h, and confirm that another package operation is not running. Fix the cause and retry a full update. Do not delete the pacman lock file while an update is active.

No sound or microphone

Check the selected input and output in the desktop's audio settings and test another application. If sound still fails, record the device name and the output of systemctl --user status pipewire wireplumber for a support report.

I need more help

Report the ZelixOS release, desktop, hardware model, exact error, and steps to reproduce it in the ZelixOS GitHub. Remove passwords and other private information from logs before sharing them.
