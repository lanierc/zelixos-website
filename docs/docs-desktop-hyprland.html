Hyprland

Hyprland

Hyprland is a Wayland compositor with dynamic tiling. Review ~/.config/hypr/hyprland.conf or ~/.config/hypr/hyprland.lua for your actual key bindings, monitor rules, startup apps, and input layout. Shortcuts shown in another distribution's guide may not match ZelixOS. Back up this file before editing it.

Useful checks: hyprctl monitors lists detected displays; hyprctl devices lists input devices; hyprctl reload rereads the configuration after a change. For a black screen after editing, restore the last working config from a text console. Screen sharing and file picker issues can also involve the desktop portal, so record the affected app and session type.

hyprctl monitors
hyprctl reload

ZelixOS setup

ZelixOS installs Waybar, Wofi and swaybg. Waybar starts with the session; Super + Space opens Wofi. If the bar or launcher is missing, inspect the ZelixOS fragment and check whether the commands exist with command -v waybar wofi swaybg. The fragment may be ~/.config/hypr/zelix.conf or ~/.config/hypr/zelix.lua; preserve its include in the main config.

Hyprland

Hyprland, dinamik döşemeli bir Wayland bileştiricisidir. Gerçek kısayollar, ekran kuralları, başlangıç uygulamaları ve klavye düzeni için ~/.config/hypr/hyprland.conf veya ~/.config/hypr/hyprland.lua dosyasını inceleyin. Başka bir dağıtımın kısayolları ZelixOS ile aynı olmayabilir. Düzenlemeden önce dosyanın yedeğini alın.

Yararlı kontroller: hyprctl monitors algılanan ekranları, hyprctl devices giriş aygıtlarını listeler; hyprctl reload değişikliklerden sonra yapılandırmayı yeniden okur. Düzenleme sonrası siyah ekran olursa metin konsolundan çalışan son yapılandırmayı geri yükleyin. Ekran paylaşımı ve dosya seçici sorunlarında masaüstü portalı da etkili olabilir; uygulama adını ve oturum türünü kaydedin.

hyprctl monitors
hyprctl reload

ZelixOS kurulumu

ZelixOS Waybar, Wofi ve swaybg kurar. Waybar oturumla başlar; Super + Space Wofi’yi açar. Çubuk veya başlatıcı görünmüyorsa ZelixOS yapılandırma parçasını inceleyin ve command -v waybar wofi swaybg ile komutları kontrol edin. Parça ~/.config/hypr/zelix.conf veya ~/.config/hypr/zelix.lua olabilir; ana yapılandırmadaki bağlantısını koruyun.
