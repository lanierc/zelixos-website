Masaüstü rehberleri

Xfce

Xfce

Xfce uses a classic panel, application menu, and configurable desktop. Its components are modular, so a missing panel does not always mean the whole session has failed. Use Settings Manager for displays, keyboard, appearance, and window behavior; use the panel's context menu to adjust launchers.

Useful checks: Open Settings Manager with xfce4-settings-manager. If the panel alone has disappeared, run xfce4-panel --restart from a terminal in the Xfce session. If the desktop is blank, check whether you selected the Xfce session at login before changing autostart entries.

xfce4-settings-manager
xfce4-panel --restart

Xfce documentation

ZelixOS setup

Use Settings Manager → Session and Startup to review startup applications, and Panel preferences to arrange launchers. The installer supplies the Materia GTK theme, Adwaita icons and a dedicated wallpaper.

Xfce

Xfce klasik panel, uygulama menüsü ve yapılandırılabilir masaüstü sunar. Bileşenleri ayrıdır; panelin kaybolması her zaman tüm oturumun çöktüğü anlamına gelmez. Ekran, klavye, görünüm ve pencere davranışı için Ayar Yöneticisi’ni; başlatıcılar için panelin sağ tık menüsünü kullanın.

Yararlı kontroller: Ayar Yöneticisi’ni xfce4-settings-manager ile açın. Yalnız panel kaybolduysa Xfce oturumundaki terminalden xfce4-panel --restart çalıştırın. Masaüstü boşsa başlangıç girdilerini değiştirmeden önce girişte Xfce oturumunu seçtiğinizi doğrulayın.

xfce4-settings-manager
xfce4-panel --restart

Xfce belgeleri

ZelixOS kurulumu

Başlangıç uygulamaları için Ayar Yöneticisi → Oturum ve Başlangıç bölümünü, başlatıcıları düzenlemek için Panel tercihlerini kullanın. Kurucu Materia GTK temasını, Adwaita simgelerini ve özel duvar kâğıdını sağlar.

Everyday use

Panel and applications

Use the application menu to start programs and the panel to switch windows. Right-click the panel to open its preferences and arrange items or launchers. Record your layout before making extensive changes.

Settings and startup

Open Settings Manager for displays, keyboard, appearance and window behavior. In Session and Startup, review applications that start with your session; disable an entry only after identifying what it does. See visual themes for appearance guidance.

Panel or desktop problems

If only the panel is missing, open a terminal in the Xfce session and run xfce4-panel --restart. If the entire session fails, check the selected session and free space, then follow troubleshooting. Back up configuration before changing or removing it.

Günlük kullanım

Panel ve uygulamalar

Programları uygulama menüsünden açın ve pencereler arasında panelden geçin. Panele sağ tıklayarak tercihleri açın; öğeleri veya başlatıcıları düzenleyin. Kapsamlı değişikliklerden önce düzeninizi not edin.

Ayarlar ve başlangıç

Ekran, klavye, görünüm ve pencere davranışı için Ayar Yöneticisi’ni açın. Oturum ve Başlangıç bölümünde oturumla açılan uygulamaları inceleyin; bir girdiyi yalnızca ne yaptığını öğrendikten sonra kapatın. Görünüm için görsel temalar rehberine bakın.

Panel veya masaüstü sorunları

Yalnızca panel kaybolduysa Xfce oturumunda bir terminal açıp xfce4-panel --restart çalıştırın. Oturumun tamamı açılmıyorsa seçilen oturumu ve boş alanı kontrol edip sorun giderme rehberini izleyin. Yapılandırmayı değiştirmeden veya silmeden önce yedekleyin.
