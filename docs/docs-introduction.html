Getting started

Why ZelixOS?

ZelixOS is an Arch-based, rolling-release Linux distribution designed to provide a streamlined desktop while preserving the flexibility of its underlying system. Install once and receive ongoing software and kernel updates through the rolling release model.

The system favors a clean starting point over a large collection of preinstalled applications. Its custom tools help with setup and maintenance, while desktop and window manager choices let you shape the system around your workflow. ZelixOS includes a graphical installer, a welcome utility, an updater, and command-line helpers to make common tasks easier to discover.

Rolling release, familiar tools

Software is delivered continuously from the Arch ecosystem. For applications shown in Zelix Hello, use its Software page first. Pacman manages official repository packages. During installation, you choose whether to install an AUR helper. Check that choice on your own system before following helper commands; keep regular backups of important files.
