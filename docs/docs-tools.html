Using ZelixOS

Zelix tools

Project utilities provide a graphical path to common setup and maintenance tasks. Names and availability may vary between releases.

ZH

Zelix Hello

Welcome hub with links to documentation, release information, support, project resources, language selection, and a keyboard-shortcuts guide.

ZU

Zelix Updater

Graphical utility for checking and applying system package updates.

Z

Zelix CLI

The zelix command offers shortcuts for updates, mirror ranking, cleanup, system information, launching Zelix Hello, language selection, and help. Run zelix help to see the commands available in your installed version.

Using the tools

Zelix Hello: first steps and software

Use the welcome screen to find documentation, support and release information. To add an application, open Software, browse the relevant category and review the available choice before installing. The available actions depend on the version installed; see installing applications for other package sources.

Zelix Updater: review and update

Connect to the internet, open Zelix Updater and check for updates. Aurora 1.0.1 lists available packages and versions and asks for confirmation before applying them. Review the list, confirm when ready, and follow the process output until it finishes. Do not run another package operation at the same time. If an update fails, save the exact error and see system maintenance.

Zelix CLI: discover commands

Open a terminal and run zelix help for the commands supported by your installed version. The CLI includes shortcuts for tasks such as updates, mirror ranking and system information. Read the help for an action before running it, especially for cleanup. Aurora also documents a language setting: replace the example with en or tr.

zelix help
zelix lang tr

If a tool is unavailable

Check the application menu and your release notes; features can differ between releases. In a terminal, command -v zelix checks whether the CLI is on your path. Record the tool name, release and exact error before asking for help. See troubleshooting for collecting useful diagnostics.

command -v zelix

Araçları kullanma

Zelix Hello: ilk adımlar ve yazılımlar

Karşılama ekranından belgelere, desteğe ve sürüm bilgilerine ulaşın. Uygulama eklemek için Software bölümünü açın, ilgili kategoriye bakın ve kurmadan önce seçeneği inceleyin. Kullanılabilir işlemler kurulu sürüme göre değişir; diğer paket kaynakları için uygulama kurma rehberine bakın.

Zelix Updater: inceleyin ve güncelleyin

İnternete bağlanın, Zelix Updater’ı açın ve güncellemeleri kontrol edin. Aurora 1.0.1, mevcut paketleri ve sürümlerini listeler ve uygulamadan önce onay ister. Listeyi inceleyin, hazır olduğunuzda onaylayın ve işlem bitene kadar çıktıyı takip edin. Aynı anda başka bir paket işlemi çalıştırmayın. Güncelleme başarısız olursa hatayı aynen kaydedip sistem bakımı rehberine bakın.

Zelix CLI: komutları keşfedin

Terminal açıp kurulu sürümün desteklediği komutlar için zelix help çalıştırın. CLI güncelleme, yansı sıralama ve sistem bilgisi gibi işler için kısayollar içerir. Özellikle temizlik işlemlerinden önce ilgili komutun yardımını okuyun. Aurora’da dil ayarı da belgelenmiştir: örnekte en veya tr kullanın.

zelix help
zelix lang tr

Bir araç bulunamıyorsa

Uygulama menüsünü ve sürüm notlarını kontrol edin; özellikler sürüme göre değişebilir. Terminalde command -v zelix, CLI komutunun arama yolunda olup olmadığını kontrol eder. Yardım istemeden önce araç adını, sürümü ve hatayı aynen kaydedin. Yararlı tanılama bilgileri için sorun giderme rehberine bakın.

command -v zelix
