bspwm

bspwm

bspwm is an X11 tiling window manager controlled through bspc. Its startup script is usually ~/.config/bspwm/bspwmrc. Keyboard shortcuts are handled separately by sxhkd, commonly configured in ~/.config/sxhkd/sxhkdrc. A desktop with no working shortcuts may simply have an inactive sxhkd process.

Useful checks: bspc query -M lists monitors. Check pgrep -a sxhkd when shortcuts fail. After editing the startup script, bspc wm -r restarts bspwm; save work first and keep a terminal open.

pgrep -a sxhkd
bspc query -M

bspwm documentation

ZelixOS setup

ZelixOS adds border, gap and feh wallpaper commands to ~/.config/bspwm/bspwmrc. Back up the script before editing, and keep it executable. The window manager and sxhkd are separate processes; inspect ~/.config/sxhkd/sxhkdrc for your actual bindings.

bspwm

bspwm, bspc ile denetlenen bir X11 pencere yöneticisidir. Başlangıç betiği genellikle ~/.config/bspwm/bspwmrc konumundadır. Klavye kısayolları ayrı çalışan sxhkd tarafından yönetilir; yapılandırması çoğunlukla ~/.config/sxhkd/sxhkdrc konumundadır. Kısayollar çalışmıyorsa sxhkd etkin olmayabilir.

Yararlı kontroller: bspc query -M ekranları listeler. Kısayollar için pgrep -a sxhkd ile süreci kontrol edin. Başlangıç betiğini düzenledikten sonra bspc wm -r bspwm’yi yeniden başlatır; önce çalışmanızı kaydedip bir terminali açık tutun.

pgrep -a sxhkd
bspc query -M

bspwm belgeleri

ZelixOS kurulumu

ZelixOS ~/.config/bspwm/bspwmrc içine kenarlık, boşluk ve feh duvar kâğıdı komutları ekler. Betiği düzenlemeden önce yedekleyin ve çalıştırılabilir durumda tutun. Pencere yöneticisi ve sxhkd ayrı süreçlerdir; kısayolları ~/.config/sxhkd/sxhkdrc dosyasından inceleyin.
