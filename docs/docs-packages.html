Software

Packages and AUR

Use Zelix Hello → Software for apps listed in its catalog. For other official repository packages, use pacman. An AUR helper is optional: the Zelix Installer asks whether to install one. Do not assume that Yay or Paru is present on every installation.

Official repositories

Keep the entire system current when refreshing package databases. Run these commands in a terminal; replace package-name with an actual repository package name.

sudo pacman -Syu
pacman -Ss package-name
sudo pacman -S package-name
Avoid partial upgrades

Refreshing package databases without upgrading the whole system can cause an unsupported partial upgrade. Avoid running pacman -Sy on its own. Use pacman -Syu for a complete update.

Optional AUR helper

The AUR contains user-maintained build recipes. If you selected an AUR helper in the installer, run command -v yay or command -v paru to find which helper is installed. Review a package's build files and source before installing it. Run AUR helpers as your regular user, without sudo.

command -v yay; command -v paru

If neither command returns a path, you did not install one or it is unavailable in your current environment. Official packages remain available through pacman.

Find and inspect a package

Search repository package names and descriptions with pacman -Ss. Before installing, use pacman -Si to see its repository, version, dependencies, and description. To inspect an installed package, use pacman -Qi. Replace the example package with the name you found.

pacman -Ss firefox
pacman -Si firefox
pacman -Qi firefox

Install, remove, and list packages

pacman -S installs a repository package. pacman -R removes the named package; pacman -Rs also removes dependencies that are no longer needed by other packages. Read the transaction summary before confirming removal. pacman -Qe lists explicitly installed packages. These commands affect only pacman packages, not Flatpaks.

sudo pacman -S firefox
sudo pacman -R firefox
pacman -Qe

Use the helper selected in the installer

The AUR is community-maintained. Check whether yay or paru exists before using its commands. Search with the helper you installed, inspect the build recipe and sources, and run it as your regular user. The examples below are alternatives, not commands to run together. If you declined the helper during installation, the official repositories and Zelix Hello still work.

yay -Ss package-name
paru -Ss package-name

When AUR packages break after a system update, check the helper's output and the package's current build instructions; AUR packages may need rebuilding. Never run a helper with sudo.

Paket arama ve inceleme

Depo paketlerinin adlarını ve açıklamalarını pacman -Ss ile arayın. Yüklemeden önce pacman -Si ile depoyu, sürümü, bağımlılıkları ve açıklamayı görün. Kurulu paketi incelemek için pacman -Qi kullanın. Örnekteki paket adını bulduğunuz adla değiştirin.

pacman -Ss firefox
pacman -Si firefox
pacman -Qi firefox

Paket yükleme, kaldırma ve listeleme

pacman -S depo paketini yükler. pacman -R adı verilen paketi kaldırır; pacman -Rs başka paketlerin kullanmadığı bağımlılıklarını da kaldırır. Kaldırmayı onaylamadan önce işlem özetini okuyun. pacman -Qe açıkça yüklenen paketleri listeler. Bu komutlar Flatpak’ları değil, yalnız pacman paketlerini etkiler.

sudo pacman -S firefox
sudo pacman -R firefox
pacman -Qe

Yükleyicide seçilen yardımcıyı kullanma

AUR, topluluk tarafından yönetilir. Komutlarını kullanmadan önce yay veya paru yüklü mü kontrol edin. Kurduğunuz yardımcıyla arama yapın, derleme tarifini ve kaynakları inceleyin; yardımcıyı normal kullanıcı olarak çalıştırın. Aşağıdaki örnekler alternatiftir, birlikte çalıştırılmaz. Kurulumda yardımcıyı seçmediyseniz resmî depolar ve Zelix Hello yine çalışır.

yay -Ss package-name
paru -Ss package-name

AUR paketleri sistem güncellemesi sonrası bozulursa yardımcının çıktısını ve paketin güncel derleme yönergelerini inceleyin; yeniden derleme gerekebilir. Yardımcıyı sudo ile çalıştırmayın.
