Installation Guide

Four steps to install

An active internet connection is required during installation. UEFI boot mode is recommended.

  1. 01

    Download the ISO

    Download the ZelixOS Aurora ISO and verify it against the official SHA-256 value when available.

  2. 02

    Flash to USB

    Write the ISO to a USB flash drive (≥8 GB) using Ventoy, balenaEtcher, or Rufus (DD mode).

  3. 03

    Boot Live Media

    Reboot your PC, open the boot menu (F12/F11/F8), and boot into the ZelixOS live environment.

  4. 04

    Run Zelix Installer

    Double-click "Install ZelixOS" on the desktop and follow the guided graphical installer.
