ZelixOS Aurora 1.0.0

After extensive testing and polishing, the full ZelixOS Aurora 1.0.0 release is here. It refines our monochrome desktop, updates core tools, and provides a clean Arch Linux foundation.

Sürüm notları27 Ekim 2026

ZelixOS Aurora 1.0.0

Kapsamlı test ve iyileştirmelerin ardından ZelixOS Aurora 1.0.0 tam sürümü yayınlandı. Bu sürüm tek renkli masaüstü deneyimini geliştiriyor, temel araçları güncelliyor ve Arch Linux tabanında sade bir başlangıç sunuyor.

Aurora 1.0.0 is a complete release focused on a polished out-of-the-box desktop, more capable Zelix utilities, and a lightweight foundation that leaves software choices in your hands.

01 · Desktop & aesthetics

A calmer, more consistent workspace

Monochrome KDE Plasma

OLED-friendly dark styling has been retuned with bright accents and more consistent contrast across panels and widgets.

A streamlined desktop

Default launchers have been cleaned up to keep the initial workspace focused and minimal.

90 curated wallpapers

The Zelix Extras wallpaper collection joins the default minimal wallpaper, ready to choose from desktop settings.

Updated boot and login themes

GRUB, Plymouth, and SDDM carry the Aurora look from boot selection through startup to the login screen.

02 · In-house applications & tools

Useful tools, refined

Zelix Installer zelixins v1.1.6

Installer
  • English is the default language; Turkish remains available on the welcome screen.
  • Dialog button states now retain readable dark-theme contrast during network checks.
  • Password confirmation and stricter username validation help catch setup errors earlier.
  • Post-install steps for local repositories and desktop setup have been improved.

Zelix Updater v1.0.4

System updates

A dedicated, lightweight graphical utility for reviewing system package updates and synchronizing pacman repositories without opening a terminal.

Zelix CLI

Terminal

The zelix command-line utility now has English localization and a built-in language switch: zelix lang [en|tr].

Fastfetch

Ready to use

A minimal system information summary is preconfigured for the terminal.

03 · A clean-slate experience

Your system, your choices

ZelixOS keeps its base image focused: no arbitrary third-party bundles, media suites, or heavyweight default applications. The ISO contains the core utilities needed for a responsive desktop, while Zelix Hello lets you install the daily applications and tools you actually want.

04 · Installation

Requirements & preparation

Architecture
x86_64 (64-bit)
Boot mode
UEFI recommended; Secure Boot disabled
Network
Active internet required during setup to fetch and verify current package signatures
Memory
2 GB minimum · 4 GB or more recommended
Storage
20 GB free space minimum
Back up before installation

Writing an ISO erases the selected USB drive, and installing can change disk partitions. Verify the target device and back up important data first.

05 · Verify your download

Check the ISO before flashing

From the directory containing the downloaded ISO, calculate its SHA-256 digest:

sha256sum ZelixOS-*.iso

Compare the result with the checksum published alongside the ZelixOS Aurora 1.0.0 ISO. A checksum from another release will not match.

04 · Kurulum

Gereksinimler ve hazırlık

Mimari
x86_64 (64 bit)
Önyükleme modu
UEFI önerilir; Secure Boot kapalı olmalı
Ağ
Güncel paket imzalarını indirmek ve doğrulamak için kurulum sırasında etkin internet gerekir

Depolama
En az 20 GB boş alan
Kurulumdan önce yedek alın

ISO yazma işlemi seçilen USB belleği siler; kurulum disk bölümlerini de değiştirebilir. Önce hedef aygıtı doğrulayın ve önemli verilerinizi yedekleyin.

05 · İndirdiğiniz dosyayı doğrulayın

Yazdırmadan önce ISO’yu kontrol edin

İndirilen ISO dosyasının bulunduğu dizinde SHA-256 özetini hesaplayın:

sha256sum ZelixOS-*.iso

Sonucu ZelixOS Aurora 1.0.0 ISO dosyasıyla birlikte yayımlanan sağlama toplamıyla karşılaştırın. Başka bir sürüme ait değer eşleşmez.
